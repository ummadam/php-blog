# PHP Blog

Простой блог с категориями и статьями, разработанный на чистом PHP без использования фреймворков.

## Технологии

- PHP 8.1+
- MySQL / MariaDB
- Smarty
- PDO
- FastRoute
- Composer
- Nginx
- SCSS

## Функциональность

- Главная страница с категориями и тремя последними статьями каждой категории.
- Страница категории со списком статей, сортировкой по дате публикации и количеству просмотров.
- Пагинация по 6 статей.
- Страница статьи с полной информацией.
- Вывод трёх похожих статей при их наличии.
- Наполнение базы данных тестовыми данными.

## Структура проекта

- `src/Controller` — контроллеры.
- `src/Model` — модели и SQL-запросы.
- `src/Service` — подключение к базе данных и настройка Smarty.
- `config` — конфигурация приложения и маршруты.
- `database` — структура базы данных и сидеры.
- `templates` — шаблоны Smarty.
- `public` — точка входа, изображения и стили.
- `resources/scss` — исходные SCSS-стили.
- `storage` — кеш и скомпилированные шаблоны Smarty.
- `nginx` — пример конфигурации Nginx.

## Установка

1. Клонировать репозиторий и перейти в директорию проекта.

2. Установить зависимости:

```bash
composer install
```

3. Создать базу данных `php_blog`.

4. Создать файл конфигурации:

```bash
cp config/database.example.php config/database.php
```

Указать в `config/database.php` параметры подключения к базе данных.

5. Импортировать структуру базы данных:

```bash
mysql -u blog_user -p php_blog < database/schema.sql
```

6. Наполнить базу данных тестовыми данными:

```bash
php database/seed.php
```

7. Сгенерировать изображения для статей:

```bash
php database/generate-images.php
```

8. Настроить Nginx и PHP-FPM. Корневая директория сайта должна указывать на папку `public`. Пример конфигурации находится в папке `nginx`.

Директории `storage/cache` и `storage/templates_c` должны быть доступны для записи пользователю PHP-FPM.

## Сборка стилей

```bash
npm ci
npm run build
```

Для автоматической компиляции SCSS при изменении файлов:

```bash
npm run watch
```

## База данных

В проекте используются три таблицы:

- `categories` — категории.
- `articles` — статьи.
- `article_category` — связи между статьями и категориями.

Одна статья может принадлежать нескольким категориям.

Повторный запуск сидера не создаёт дубликаты записей.

При разработке использовалась MariaDB 10.6. SQL-запросы написаны с учётом совместимости с MySQL 8, отдельное тестирование на MySQL не проводилось.

## Особенности реализации

Проект построен на основе упрощённой архитектуры MVC.

Для работы с базой данных используются подготовленные запросы PDO. Сортировка и пагинация выполняются на стороне базы данных.

Похожие статьи определяются по количеству общих категорий и дате публикации.

Количество просмотров хранится в базе данных и используется для отображения и сортировки статей.
